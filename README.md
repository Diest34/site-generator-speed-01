A faster drop-in for make.fun's own makefun-site 1.0.0 static site generator: the same output tree, byte for byte, at about 1.9x the speed on the practice set (12/12 freshly drawn cases identical to the reference).

`solve.js` is a dependency-free ES module whose `run(input)` returns makefun-site 1.0.0's answer for one case's site. `main.ts` is the harness driver: it reads every case from `/input/cases.json` (or `$MAKEFUN_INPUT_DIR`), answers each with `run`, and writes `/output/answers.json` (or `$MAKEFUN_OUTPUT_DIR`).

## Run it

```sh
node main.ts
```
